### Payoff Matrix

The Payoff Matrix:

| **Player A / Player B** | **Cooperate (C)** | **Defect (D)** |
|-------------------------|-------------------|----------------|
| **Cooperate (C)**       | R = 0.8           | S = 0          |
| **Defect (D)**          | T = 1.0           | P = 0.2        |


The Q values matrix is structured as follows:
Q_{00}, Q_{10}, 
Q_{01}, Q_{11}
Where the first subscript represents the action, and the second represents the state.
